Используются `flat/50m/multi_event.parquet` (прослушивания, лайки, дизлайки) и таблицы соответствия трек - исполнитель и трек - альбом.

## Задача

Для каждого пользователя строится top-10 новых треков на следующие 14 дней. Релевантный трек - новый для пользователя, прослушанный хотя бы раз на 50% и больше или лайкнутый, без дизлайка. Разбиение по времени: train / validation (14 дней) / test (последние 14 дней). Подвыборка: 10 000 популярных треков и 2 500 случайных пользователей, 1.71 млн взаимодействий.

## Модели

| Файл | Модель |
|---|---|
| `models/itemknn.py` | Item-based kNN |
| `models/ials.py` | iALS |
| `models/ease.py` | EASE |
| `models/fm.py` | Factorization Machine с метапризнаками |
| `models/ials_custom.py` | iALS с кастомным целевым сигналом |
| `models/base.py` | общий интерфейс и бейзлайн по популярности |

`utils/` - подготовка данных, метрики и перебор параметров.
